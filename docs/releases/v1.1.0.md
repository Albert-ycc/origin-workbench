# Origin Workbench v1.1.0

Origin v1.1.0 is the first 1.1 release line. It keeps the product focused on a single local user, promotes the desktop agent roster into a badge-card experience, removes leftover team-collaboration mailbox paths, and adds the first mobile companion draft.

## Highlights

- Agent roster is now a responsive badge-card grid, giving the offline avatar set much higher visual weight while keeping compact local status, runtime, join date, model, and run-count information.
- Team-oriented mailbox logic has been removed from the product path. Origin now treats captured files and notes as local-user attachments instead of shared collaboration inbox items.
- Origin Mobile preview is included under `apps/mobile/`. It can run as a LAN PWA, connect to the Mac backend, load the local workspace, review missions and agents, capture text ideas, and upload short voice notes.
- The model runtime and agent detail surfaces were tightened with focused tests around runtime selection, profile/memory tabs, and local-only behavior.
- Release docs now describe the current Origin positioning: desktop-first local workbench, with mobile as a companion preview rather than a cloud or team client.

## Compatibility Notes

- The desktop app remains the primary supported shell.
- Mobile is a preview and expects the Origin backend to be reachable from the phone on the same LAN.
- This release does not add team workspaces, invitations, cloud onboarding, or shared mailboxes.
